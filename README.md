# SzarlotkaDiscordFucker
A simple Discord.py bot for server raiding, made for educational purposes only, recommended using VPN because you can get rate limited and you will need to unplug and plug again your router. 

# Needed libraries
- discord - `pip install discord`

# How to install
1. Head over to [releases](https://github.com/TheNegatyww/SzarlotkaDiscordFucker/releases)
2. Download the .py file.
3. Head oved to [Discord Developer Portal](https://discord.com/developers/applications) to create application.
4. **IMPORTANT:** Enable Messeage Content Intent and Member Content Intent
5. Generate new token (Don't share it to others!!!)
6. Paste token on 11th line
7. Run the app (Make sure you have every library needed!)
